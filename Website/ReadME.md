# WEBD3100 Workshop 03A

## Overview

This project demonstrates the creation of a colour system using CSS design tokens, semantic variables, responsive layouts, and dark mode support.

## Features

- Design Tokens
- Semantic Colours
- Light Theme
- Dark Theme
- CSS Grid Layout
- Flexbox Components
- Accessible Focus States

## Colour Selection

The primary colour is blue because it communicates trust, clarity, and professionalism.

## Accessibility

All interface elements use semantic tokens and visible focus indicators to improve accessibility.

## Running the Project

Open index.html using Live Server or any modern web browser.
